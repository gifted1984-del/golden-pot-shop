# 岩谷 努｜自動運転開発ドライバー応募用ポートフォリオ

`turing-portfolio/` は、既存アプリに影響を与えない独立した静的ポートフォリオです。

## 内容

- 大型バス運転・自動車整備・電装／空調修理の経験
- 安全最優先、手順遵守、事実確認、記録・報告・共有の姿勢
- 自動運転の実務経験はないことを明記し、整備・製造・大型車両使用の視点を強みとして表現
- EVは「自家用車でEVを使用」と記載
- 架空の車両・人物によるAI生成コンセプトイメージを使用

## 表示

`index.html` を静的ホスティングで配信してください。画像には実在の人物・車両ではないことを明記しています。
