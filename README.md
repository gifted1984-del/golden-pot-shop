# 黄金堂 — Golden Pot Store

> V1（初期版）と、AIをフル活用してブラッシュアップしたV2を比較できるポートフォリオです。  
> まずは下の2つの公開サイトを開き、同じ商品テーマがどのように進化したかをご覧ください。

## 公開ページを比較

| | V1 — 最初に制作したアプリ | V2 — ブラッシュアップ版 |
|---|---|---|
| **コンセプト** | Rails学習の成果を形にした、シンプルな壺ショップ | 物語・演出・購入デモまで含む体験型ストア |
| **ホームページ** | [V1を開く](https://golden-pot-shop-1.onrender.com) | [V2を開く](https://golden-pot-shop-v2.onrender.com) |
| **管理アプリ** | [V1管理画面を開く](https://golden-pot-shop-1.onrender.com/admin/dashboard/index) | [V2管理画面を開く](https://golden-pot-shop-v2.onrender.com/admin/dashboard) |
| **ソースブランチ** | [main](https://github.com/gifted1984-del/golden-pot-shop/tree/main) | [v2/experience](https://github.com/gifted1984-del/golden-pot-shop/tree/v2/experience) |

## 進化のポイント

| 比較項目 | V1（初期版） | V2（ブラッシュアップ版） |
|---|---|---|
| **見た目** | 黒と金を基調にした基本レイアウト | きらびやかな背景、光の演出、動く金貨、カードホバー |
| **商品一覧** | 金・銀・銅 × 大・中・小を一覧表示 | 同じ9商品を維持しつつ、サイズ差が伝わる画像演出を追加 |
| **探しやすさ** | 商品一覧を中心に閲覧 | 商品名検索、素材、サイズの複合フィルター |
| **ストーリー性** | 商品を直接見る構成 | 素材を巡るストーリー型のホームページ |
| **購入体験** | 商品閲覧のみ | クレジットカード入力までの購入デモ（実決済なし） |
| **管理画面** | 初期版の管理ダッシュボード | V2管理者Console、環境変数によるログイン保護 |
| **公開環境** | Render無料プラン | Render無料プラン（V2専用URL） |

## 比較のおすすめ手順

1. [V1ホームページ](https://golden-pot-shop-1.onrender.com)で、最初のシンプルな商品一覧を見る
2. [V2ホームページ](https://golden-pot-shop-v2.onrender.com)で、背景・動き・ストーリー・フィルターを体験する
3. [V1管理アプリ](https://golden-pot-shop-1.onrender.com/admin/dashboard/index)と[V2管理アプリ](https://golden-pot-shop-v2.onrender.com/admin/dashboard)を比較する
4. V2の商品詳細から購入デモへ進み、実際には購入できないことを確認する

## V2の主な機能

- 金・銀・銅 × 大・中・小のコレクション表示
- 商品名・素材・サイズによるカタログ絞り込み
- 背景アニメーション、光の粒、金貨のモーション
- レスポンシブ対応
- クレジットカード入力を含む購入デモ（実決済・保存・購入は一切なし）
- 管理者Console V2
- Render無料プランで公開

## 注意事項

このサイトはポートフォリオ用の架空のショップです。実際の商品販売・購入は行っていません。  
購入デモでは実在のカード情報を入力せず、画面上のテスト用番号だけを使用してください。
